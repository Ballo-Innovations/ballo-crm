# Key UX Flows (each is a demo beat)

1. **Lead → Opportunity:** Leads list → [Convert] → choose existing account or create → opportunity form (products, amount, close date) → lands on Kanban in QUALIFY with Bronze badge.
2. **Score explanation:** Kanban card → drawer → ScoreRing → FactorList → "Add technical buyer" action → add committee member → score updates live → badge turns Gold.
3. **Engagement lifts grade:** Engagement → Log DC tour for account → return to opportunity → engagement factor up → grade Platinum (if budget confirmed + economic buyer engaged).
4. **Recommendation → opportunity:** Account 360 → Recommendations → DRaaS 74% → [Create opportunity from recommendation] → prefilled.
5. **Contract:** Opportunity WON → [Generate contract] → template + merge → PDF preview → send → open /sign/token in incognito → sign → status SIGNED → appears in renewals (end date seeded close).
6. **Executive:** Dashboard → VSI → Mining → whitespace → click account.
7. **Admin:** Audit log shows the above changes with diffs; Integrations tab shows mock ERP push from the won deal.
