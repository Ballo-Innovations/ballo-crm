Command palette (⌘K) — 3 options

Global search plus quick actions. In any window, click the search bar or press ⌘K / Ctrl K (opens the window you last clicked), then type — try “fib”, “nyali”, “new” or “pipe”. ↑ ↓ to move, Enter to open, Esc to close.

Same in every option: ⌘K / Ctrl K opens it from anywhere; empty state shows recent items and the most-used actions; results are grouped (Actions, Opportunities, Accounts, Leads, Contacts) with matched letters underlined; Enter opens records in the drawer and runs actions; results come from one search endpoint scoped to what the user may see; on phones it opens full-screen.
