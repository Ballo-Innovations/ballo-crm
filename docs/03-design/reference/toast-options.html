Toasts — 3 options

Toasts confirm every save and offer Undo where it's cheap. Press the buttons above each window to fire real toasts — try several quickly to see stacking, and hover a toast to pause its timer.

Same in every option: success 4s, with Undo 6s, errors stay until closed; hovering pauses the timer; max 3 visible (oldest goes first); announced to screen readers (role="status", errors role="alert"); never used for anything the user must act on — that's a dialog.
