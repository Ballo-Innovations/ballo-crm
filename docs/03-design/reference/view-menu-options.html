View menu — 4 options

The View dropdown switches between saved views (All deals, My deals, Closing this month…). Each menu starts open: pick a view and the list changes; set a filter and “Save as new view” appears. This menu style would also be used for the ⋯ row menu and the user menu.

Same in every option: ↑ ↓ move through items, Enter picks, Esc closes and returns focus to the button; the current view is in the URL; changing filters on a saved view marks it “edited” with Save / Save as new; team views are read-only for reps; on phones the menu opens as a bottom sheet.
