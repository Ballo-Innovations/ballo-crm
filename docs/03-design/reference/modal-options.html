Modals & confirm dialogs — 3 options

Modals are only for decisions that must be made before continuing — everything else uses the drawer. In each window, try the drawer buttons: Mark as lost (pick a reason), Delete (type the name to confirm) and edit the value then ✕ close to get "Discard changes?". Close with Cancel, Esc or by clicking outside.

Same in every option: one clear question as the title; the consequence in one line; the safe choice (Cancel) on the left, the action on the right named for what it does ("Mark as lost", never "OK"); solid red only for destructive actions; focus moves into the dialog and returns to the button that opened it; Esc and clicking outside cancel (except while saving); the action shows a spinner, then the dialog closes and a toast confirms, with Undo where possible.
