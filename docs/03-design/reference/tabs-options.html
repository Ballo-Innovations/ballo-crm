Tabs & segmented controls — 3 options

Tabs switch between sections of the same thing (All / Target accounts, drawer sections); segmented controls switch how you view it (Board / List, 7D / 30D). Click them — or focus one and use the arrow keys.

Same in every option: counts sit in a small pill inside the tab; the selected tab is in the URL (?tab=target) so it survives reloads and can be shared; ← → move between tabs and Home/End jump to the ends; on phones a row of tabs scrolls sideways instead of wrapping; never more than 6 tabs in a row.
