# Compass — one-pager for judges

**What:** A B2B commercial operations platform for Infratel: CRM + pipeline, account-based marketing, Vertical Sales Index, opportunity maturity grading (Bronze→Platinum), explainable cross-sell recommendations, contract generation with e-signature, and a centralised customer information system with RBAC and audit.

**Why it's different:** Every score, grade and recommendation is explainable from visible factors. Intelligence is built in, not bolted on.

**Coverage:** All Challenge 2 capability areas implemented; external integrations (email, SMS, telephony, ERP, eSPF) delivered as a documented adapter layer with a live mock service.

**Tech:** Next.js 15 · TypeScript · PostgreSQL/Prisma · MinIO · Anthropic API (narratives, cached) · Docker Compose · GitHub Actions. Tests: unit + Playwright.
